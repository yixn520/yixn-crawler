🧠 工作原理

Yixn 爬虫采用两步式抓取：

```
首页/列表页  →  找出所有文章链接  →  逐个进入  →  提取正文  →  存 TXT
   (第一步)                            (第二步)
```

第一步：自动识别文章链接

· 解析页面所有 <a> 标签
· 按「域名 + 第一层路径」聚类
· 找出重复最多的模式（如 /posts/xxx 出现 20 次）
· 过滤导航词（首页、关于、标签、下一页等）

第二步：正文提取策略

1. 用 HTMLParser 遍历页面
2. 跳过 <script> / <style> / <nav> / <footer> 等非正文标签
3. 遇到 <p> / <div> / <h2> 等块级标签时换行
4. 过滤掉短行（导航残留通常很短）
5. 去掉连续重复行
6. 拼接为最终正文

❓ 常见问题

Q1：提示 "未提取到任何数据" 怎么办？

· 确认目标页面是静态渲染（右键查看源码能看到文章标题）
· 有些博客首页只显示摘要，请换成文章列表页或归档页
· 若页面完全是 JS 渲染，自动模式无法识别，需要其他工具

Q2：脚本需要安装第三方库吗？

不需要。Yixn 爬虫只使用 Python 标准库：

· urllib — 网络请求
· re — 正则表达式
· html.parser — HTML 解析
· json — 数据序列化

Q3：手机上怎么用？

安卓推荐 Termux（pkg install python），或 Pydroid 3 直接打开运行。iOS 可用 a-Shell。

Q4：抓取速度太快会被封吗？

建议间隔 1~3 秒，脚本已内置延时参数。目标网站压力较大时请加大间隔。

Q5：可以抓微信公众号 / 知乎吗？

不保证。这些平台页面结构复杂，部分有反爬机制，自动模式可能失效。建议仅用于个人博客备份。

Q6：导出的 TXT 是乱码怎么办？

文件为 UTF-8 编码，请用支持 UTF-8 的编辑器打开：

· VSCode
· Notepad++
· 手机端 MT 管理器
· Sublime Text

Q7：支持哪些类型的博客？

已测试通过：

· Hexo
· Hugo
· WordPress（静态化）
· Jekyll
· 纯静态 HTML 博客

未测试或不保证：

· 微信公众号
· 知乎 / 掘金 / CSDN
· 动态渲染的 SPA 应用
